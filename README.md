# BAH BUSINESS

Application web de gestion d'entreprise pour les petits commerces.

## MVP
- Tableau de bord
- Produits et stock
- Ventes
- Clients
- Dépenses
- Rapports
- Paramètres
- Monnaie : FCFA

## Démarrage local
Ouvrir `index.html` dans un navigateur ou utiliser Live Server dans Visual Studio Code.

Branche de développement : `bah-business`
